
Ewords

Ewords is an offline mobile application designed to help students learn English through categorized common vocabulary based on proficiency levels.

The app provides a simple and organized learning experience, making it easier for learners to improve their vocabulary anytime without an internet connection.


---

Features

Offline access to vocabulary

Words organized by proficiency level

Quiz for each unit

Reading passages

Favourite words system

Scores and progress tracking

Simple and clean user interface

Fast and lightweight experience



---

Tech Stack

Flutter

Dart

SQLite
